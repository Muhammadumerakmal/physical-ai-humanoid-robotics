## Architecture Diagram

A humanoid's intelligence is a stack of layers, each building on the one below
it — from the physical body up to the tasks and interfaces people interact with.

```mermaid
flowchart TB
    HW[Hardware layer: sensors, actuators, compute]
    ROS[Robot Operating System: ROS 2 middleware]
    AI[AI models: perception, VLA, LLM]
    AG[Agent layer: reasoning, planning, tool use]
    AP[Application layer: tasks, user interfaces]
    HW --> ROS --> AI --> AG --> AP
```
