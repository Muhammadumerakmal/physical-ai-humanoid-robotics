This appendix lists capstone project ideas to apply the concepts learned in this book.

### 1. Minimalist Obstacle-Avoider
**Goal:** Build a wheeled robot that navigates a room using sensor data.
* **Core Concepts:** Sensors (Lidar/Ultrasonic), Kinematics, PID Control.
* **Expected Outcome:** A robot that can map a room and avoid collisions without human input.

### 2. Humanoid Motion-Cloner
**Goal:** Create a humanoid robot that imitates your movements using a web camera.
* **Core Concepts:** Computer Vision (Pose Estimation), Kinematics, ROS 2.
* **Expected Outcome:** A simulated (or real) humanoid model mimicking your arm and torso gestures in real-time.

### 3. RL-Based Locomotion Trainer
**Goal:** Train a quadruped or biped to walk using Reinforcement Learning in Isaac Sim.
* **Core Concepts:** Reinforcement Learning, Dynamics, Simulation.
* **Expected Outcome:** A trained policy capable of traversing uneven terrain in the simulator.

### 4. Language-Instructed Manipulator
**Goal:** Build a VLA-powered agent that can sort household objects based on natural language commands.
* **Core Concepts:** VLA Models, LLMs, Computer Vision, Manipulation.
* **Expected Outcome:** A robot arm that picks up a "red apple" when asked.
