# Physical AI and Humanoid Robotics

**Building Intelligent Machines** — a long-form technical book about physical AI and
humanoid robots, built as a documentation website with
[Docusaurus](https://docusaurus.io/).

The book covers the full stack of an embodied intelligent machine: sensing and
perception, actuation and control, learning and autonomy, and the systems work
needed to deploy it. Content lives in `docs/`, organized into five parts plus
appendices (see `sidebars.ts`).

## Project structure

```
physical-ai-book/
├── docs/                    # The book's content (Markdown/MDX)
│   ├── intro.mdx            # Introduction / how to read the book
│   ├── part1-foundations/   # Part I — Foundations
│   ├── part2-perception/    # Part II — Perception & Sensing
│   ├── part3-control/       # Part III — Actuation & Control
│   ├── part4-learning/      # Part IV — Learning & Autonomy
│   ├── part5-deployment/    # Part V — Systems & Deployment
│   └── appendices/          # Glossary, further reading
├── src/
│   ├── css/custom.css       # Theme / design tokens (light & dark)
│   └── pages/               # Landing page
├── static/img/              # Logo and favicon
├── docusaurus.config.ts     # Site configuration
└── sidebars.ts              # The book's table of contents
```

Each part is a sidebar category whose items are **autogenerated from its folder**:
drop a new `NN-title.mdx` file into `docs/partX-*/` and it appears in the
sidebar automatically (chapters sort by filename / `sidebar_position`).

## Requirements

- Node.js ≥ 20
- npm (or your package manager of choice)

## Local development

```bash
npm install
npm run start
```

This starts a development server at http://localhost:3000 with live reload.

## Build

```bash
npm run build
```

Generates static output in `build/`, ready to serve from any static host.

## Preview the production build

```bash
npm run serve
```

## Type-check

```bash
npm run typecheck
```

## Deployment

The site is configured for static hosting (GitHub Pages, Netlify, Vercel, …).
Before publishing, update `url`, `organizationName`, and `projectName` in
`docusaurus.config.ts`.
