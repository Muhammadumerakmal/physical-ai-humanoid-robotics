# Contributing to Physical AI and Humanoid Robotics

Thank you for your interest in contributing! This project is a community-driven textbook. Your contributions help make robotics and AI education accessible to all.

## How to Contribute
1. **Report Issues**: Found a bug or a confusing explanation? Please open an [issue](https://github.com/Muhammadumerakmal/physical-ai-humanoid-robotics/issues).
2. **Improve Content**: Submit a pull request to edit any chapter or appendix.
3. **Add Examples**: Have a great robotics example? Create a new exercise or code snippet.

## Style Guide
- **Tone**: Professional, engineering-focused, and accessible.
- **Formatting**: Use Markdown (MDX) for content. Follow the existing chapter template (`docs/_templates/chapter-template.mdx`).
- **Diagrams**: Use Mermaid syntax for all diagrams.

## Development Workflow
1. Fork the repository.
2. Clone your fork: `git clone <url>`
3. Install dependencies: `npm install`
4. Run locally: `npm start`
5. Create a branch and submit your pull request!
