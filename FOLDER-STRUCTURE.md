# Repository Structure

- `docs/`: Markdown (MDX) source files for the book content, organized by part.
- `src/`: Source code for React components and styles.
  - `components/`: Reusable components (e.g., `Educational/` for interactive learning).
  - `css/`: Global styles and design system.
  - `pages/`: Custom landing page and layout components.
- `static/`: Static assets (images, favicon, etc.).
- `agent/`: Serverless function code for the book assistant.
- `docusaurus.config.ts`: Main configuration file.
- `sidebars.ts`: Sidebar navigation structure.
