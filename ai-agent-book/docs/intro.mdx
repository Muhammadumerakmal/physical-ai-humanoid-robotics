# About This Book

Welcome to **AI Agents in Practice: Building, Deploying, and Selling Autonomous
Workers**.

AI agents are software that do more than answer — they *act*. They call tools,
make decisions, and run for hours toward a goal without a person steering every
step. This book is a practical, engineering-first guide to building them: from
the LLM basics underneath, through agent architectures, to shipping a worker
that runs 24/7 and getting paid for it.

## What This Book Is

A single source of truth for the full agent stack, in five parts:

- **Foundations** — what an agent is, how language models work, prompting, tools, and memory.
- **Agent architectures** — reasoning loops, frameworks, multi-agent systems, and evaluation.
- **Building agents** — skills, the Model Context Protocol, spec-driven development, and turning a script into a worker.
- **Deployment** — containers, Kubernetes, observability, and cost control.
- **The business of agents** — the economics of digital workers and how to get paid.

## Who This Book Is For

- **Software developers** — you already write code; this book shows you how to put an LLM inside a system that ships.
- **AI engineers** — you know models; this book is about the engineering around them: tools, state, deployment, and evals.
- **Entrepreneurs and domain experts** — you know a problem worth automating; this book gives you the vocabulary and the playbook.

## What You'll Be Able to Do

By the end you will be able to:

- Explain the agent loop and where each failure mode lives.
- Build an agent that calls tools, uses memory, and completes a multi-step task.
- Wrap an agent in a framework, evaluate it, and guard it.
- Containerize and deploy it with monitoring and cost controls.
- Make the case for when an agent is worth building — and when it isn't.

## Find Your Path

- **Straight through** (recommended) — Parts I–V in order.
- **Builder first** — jump to Part III (building) and Part IV (deployment), then come back for the theory.
- **Founder focus** — start with Part V (business) to pick the problem, then learn to build it.
